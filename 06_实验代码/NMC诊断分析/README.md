# NMC 波形增量诊断（基于 CPU 复现代码）

## 背景

CPU 复现代码在 NMC/石墨数据上得到 R0 2.030、A2 2.026 pp，R0 − A2 = +0.004 pp（p = 0.90），即没有波形增量。作者用原始代码重跑后得到 R0 1.968、A2 2.132 pp，R0 − A2 = −0.163 pp（Holm p = 0.0004，39/44），增量存在。

本目录原本用于诊断复现代码"为什么没有增量"，设计了 5 项诊断，完成 4 项：

| 目录 | 诊断内容 | 状态 |
|---|---|---|
| `errors/` | 误差出现在哪些 SOH 区间、工况、电芯 | 完成 |
| `soc9/` | 改用 NMC 原始数据全部 9 个 SOC 重训 | 完成 |
| `redundancy/` | 波形 ΔV 在 50 项人工特征之外还有没有信息 | 完成 |
| `physics/` | 老化如何改变脉冲；绝对电压水平假设 | 完成 |
| （backbone） | 神经网络主干训练是否充分 | 未运行（拿到原代码结果后中止） |

原计划还有"综合分析"和"对抗式复核"两步，也一并中止。下面的结论直接取自各项的 `results.json`，没有经过独立复核。

## 主要发现

### 1. 关键发现：复现代码的主干里有"绝对电压水平"特征（`physics/`）

- **NMC 的绝对电压本身就携带 SOH 信息。**
  - NMC 开路电压曲线有斜率。随着容量衰减，每次脉冲时的实际 SOC 偏离名义值。
  - 所以脉冲前电压 V0 与 SOH 高度相关：NMC 六个工况 |ρ| 平均 0.93（0.82–0.97），LFP 只有 0.36。
  - 用 V0 预测"库仑计 SOC − 名义 SOC"，NMC 的 R² = 0.964，LFP 只有 0.489。
- **复现代码的特征是在绝对电压 V 上算的**（`glob_V0`、`glob_V100`、`glob_q*`、`seg_*_intercept` 等）。
  - NMC 第 0 折选中 6 项这类特征，LFP 基本不选（5 折中只有 1 折选了 1 项）。
  - 波形分支只看首点作差后的 ΔV，看不到绝对电压水平。
- **GBDT 对照**（只换输入，其余设置相同）：

  | GBDT 输入 | NMC | LFP |
  |---|---|---|
  | 只有 τ | 8.804 | 2.881 |
  | V0 + τ + 工况 | 3.090 | 1.443 |
  | 去掉绝对水平特征 | 1.012（比完整特征差 0.077） | 1.027（不变） |
  | 完整 50 项特征 + τ | 0.935 | 1.028 |

- **神经网络对照（NMC，3 个种子）**：把 28 项绝对水平特征从主干候选中去掉后，复现代码也出现了波形增量。

  | 模型 | RMSE (pp) |
  |---|---|
  | A2（去掉绝对水平特征） | 2.098（比原 A2 差 0.072，p = 0.016） |
  | R0（去掉绝对水平特征） | 1.940 |

  - 两者之差 **R0 − A2 = −0.158 pp（−0.205 至 −0.112），p = 0.0002，36/44 个电芯改善**。
  - 这与原代码的结果几乎一致：增量 −0.163 对 −0.158，A2 2.132 对 2.098。
- **解释**：在复现代码里，主干已经通过绝对电压特征拿到了 SOC 偏移带来的 SOH 信息，波形分支能补的信息被提前"用掉"了。原代码的特征可能不含或没有选中这类绝对水平特征。**这一点需要对照原代码的特征定义确认**（补充说明 S1 里特征是在 V 还是 ΔV 上计算）。

### 2. 误差结构（`errors/`）

- **NMC 上复现代码的"零增量"是正负抵消的结果**：

  | 区间 | R0 − A2 (pp) | 说明 |
  |---|---|---|
  | 第一次 RPT（SOH = 100%） | +0.316 | R0 更差，只有 9/44 个电芯改善 |
  | SOH ≥ 90%（不含第一次 RPT） | +0.140 | p = 0.014 |
  | 80%–90% | −0.074 | p = 0.11 |
  | 72%–80% | −0.078 | p = 0.07 |
  | < 72% | −0.126 | p = 0.12 |

- **神经网络有明显的"向均值收缩"**：
  - SOH < 60% 的点被高估 3.5 pp；新电池（第一次 RPT）被低估 3.7 pp，GBDT 几乎无偏。
  - 校准斜率：R0 0.893，GBDT 0.980。
- **神经网络在 44 个电芯上全部不如 GBDT**，平均差 1.095 pp，不是少数电芯造成的。
- **复现代码在 LFP 上的增量也随种子波动**：3 个种子分别是 −0.081、+0.031、−0.089。

### 3. 全部 9 个 SOC（`soc9/`）

- 数据：24,048 条记录、44 个电芯，清洗没有剔除任何记录。
- 结果：R0 2.105、A2 2.088、GBDT 0.866 pp；R0 − A2 = +0.017（−0.063 至 0.090），p = 0.67。
- 没有任何一个 SOC 在 Holm 校正后显著受益。**数据量少不是原因。**

### 4. 信息冗余（`redundancy/`）

- **在每个脉冲工况内部**，50 项特征 + τ 对波形 ΔV 前 10 个主成分的解释度（GBDT R²）：NMC 0.994，LFP 只有 0.183。也就是说，NMC 的波形几乎完全可以由已选特征重建，LFP 不能。
- **GBDT 加入 ΔV 都没有改善**：NMC 0.935 → 0.949（p = 0.42），LFP 1.023 → 1.020（p = 0.69）。
- **A2 的残差主要能由人工特征本身预测**，说明神经网络主干没有充分利用这些特征。下面用的是种子平均后的预测（RMSE 与表头值略有差异）：

  | | NMC | LFP |
  |---|---|---|
  | A2 原始 RMSE | 1.939 | 1.449 |
  | 用特征 + τ 预测并修正残差后 | 0.965 | 1.073 |
  | 再加 ΔV 的额外改善 | −0.022（p = 0.009） | −0.008（p = 0.31） |

## 对论文的意义

1. 论文中 NMC 的结果应采用原代码（波形增量 −0.163 pp）。复现代码的零增量来自特征实现上的差异，不能说明方法本身在 NMC 上无效。
2. 波形增量是否出现，取决于主干特征里有没有绝对电压水平信息。补充说明 S1 应写清楚各族特征是在绝对电压还是首点作差电压上计算的。
3. 神经网络在 NMC 上明显不如 GBDT，主要原因是主干对人工特征利用不足、预测向均值收缩，而 NMC 的 SOH 范围更宽（41%–100%），这个问题更突出。这与 4.4 节"学习器依赖"的论述一致。
