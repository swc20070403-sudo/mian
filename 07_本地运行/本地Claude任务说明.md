## 一、背景

论文是"融合短时脉冲电压波形与人工特征的 LFP 电池 SOH 估计"。模型如下：
- **R0**：MLP 人工特征主分支 + PatchTST 波形补充分支，K = 50，λ = 0.1。
- **A2**：只有人工特征主分支。

论文现在**只和神经网络比较**，所以下面所有实验都**不需要跑 GBDT、随机森林、SVR、Ridge、GPR 等传统模型**。

论文 4.6 节的实验原先用的是另一套 CPU 复现代码，现在要全部换成原代码的结果。要求如下：
- 数据划分、清洗、K、λ、种子都和论文主结果一致：LFP 64 个电芯，5 折电芯互斥，种子 0/1/2。
- 冻结文件一律不改。新建输出目录，例如 `outputs/rerun_46_YYYYMMDD/`。
- 凡是偏离原流程的地方（比如需要绕开写死的行数、电芯数），都写进运行记录。做法可以参照 `run_followup.py` 和之前的 `nmc_original_code_20261007`。
- 指标统一用论文口径：先在每个电芯–RPT 组内对 6 个工况取平均，再算每个电芯的 RMSE，最后对电芯取平均（电芯宏平均 RMSE，单位 pp）。三个种子取平均。
- 配对统计：按外层折分层的电芯 bootstrap（5,000 次）给 95% 置信区间，双侧符号翻转检验（5,000 次）给 p 值，并报告改善电芯数和 d_z。

## 三、4.6 节重跑（LFP，只跑 R0 和 A2）

| 编号 | 实验 | 做法 |
|---|---|---|
| 3.1 | 留一工况组 | 11 个循环工况组依次整组留作测试，验证电芯从其余组抽取。报告 R0、A2 的电芯宏平均 RMSE 和 R0 − A2 配对统计，以及每组的组均 RMSE |
| 3.2 | 循环数 ±10% 误差 | 用 5 折已训练模型，测试时把累计循环数乘以 1.1 和 0.9，模型不重训 |
| 3.3 | 匹配噪声 | 在特征提取前给全部电压加零均值高斯噪声（σ = 1 mV、2 mV），训练和测试都加，模型重训 |
| 3.4 | 只在测试加噪声 | 用干净数据训练的模型，只在测试电压加 σ = 0.5 mV 噪声 |
| 3.5 | 脉冲数 | 每个 RPT 只用 1、2、…、6 个脉冲的预测求平均。报告每种脉冲数下所有组合的平均 RMSE 和范围（最小～最大）；另报只用 3 个充电脉冲的 RMSE |
| 3.6 | 积分梯度归因 | 对 R0 的 101 点波形输入算积分梯度（32 步，基线为全零的标准化波形）。报告 C/5 段（1–30）、1C 段（31–40）、静置段（41–100）每个采样点的平均 \|IG\|，分充电和放电各给一条曲线 |
| 3.7 | 计算开销 | R0 和 A2 的参数量、每脉冲 FLOPs、单线程 CPU 推理时延（批量 1，重复 1,000 次取中位数），以及 143 项波形特征提取的耗时 |

## 四、NMC 上的 15 种编码器组合矩阵

- **做法**：用原代码在 NMC/石墨数据上跑论文第 4.1 节的 3 × 5 矩阵。主分支 MLP / ResNet / FT-Transformer × 波形分支 CNN / MLP / TCN / 逐点 Transformer / PatchTST，5 折 × 3 个种子，共 225 次训练。数据与 NMC 主结果相同（20/50/90% SOC，8,016 条记录，清洗阈值 0.3 V / 0.8 V）。
- **报告内容**：
  - 15 种组合各自的电芯宏平均 RMSE（3 × 5 表）；
  - 平方和分解：主分支、波形分支、组合依赖三项各占组合间差异的百分比，分全部 15 种组合和去掉 FT-Transformer 两种情况；
  - 每种主分支下 5 种波形编码器的排名（重点看 PatchTST 的排名）；
  - 最优组合和 MLP + PatchTST 的位置。
- **用途**：检验"组合依赖"在 NMC 上是否也成立，回应"矩阵只在 LFP 上做过"的质疑。
- **耗时提示**：在 CPU 上，FT-Transformer 和逐点 Transformer 的组合较慢；有 GPU 的话用 GPU。
